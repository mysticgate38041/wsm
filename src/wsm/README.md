# POC WSM — arsip source

Direktori ini menyimpan loader, engine dan installer POC historis. Build rilis aktif memakai [src/wsm-v2](../wsm-v2/README.md); perubahan produksi dikerjakan di sana.

Source lama dipertahankan untuk penelusuran laporan dan perbandingan historis. Perintah/path toolchain pada skrip POC mencerminkan lingkungan pengembangan saat itu. Lihat [arsip sesi](../../docs/history/README.md) untuk konteks dan [panduan build terkini](../../docs/BUILDING.md) untuk jalur yang didukung.
