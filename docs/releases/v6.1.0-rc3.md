# WSM 6.1.0 RC3

Perbaikan crash Clear Stage pada dungeon mobil: damage diproses lewat pipeline game pada UnityMain, dengan snapshot target melalui GC handles, pembatalan saat scene berubah, exception handling dan acknowledgement setelah eksekusi. OHK/One HP mengikuti dispatcher yang sama. Worker sweep lama dan pemanggilan Die ganda dihapus dari jalur produksi.

SIGSEGV guard tidak lagi melakukan host siglongjmp melintasi managed/Houdini calls yang dibungkus. Polling scene/karakter saat semua fitur OFF dikurangi. Crash lobby akibat LMKD membunuh anak pengawas ditangani sebagai masalah kapasitas memori emulator; ZIP tidak mengubah atau menonaktifkan pengawas game.

Target tetap Guardian Tales 3.54.0/code 423, Android API ≥26, x86_64/arm64-v8a. Semua kontrol mulai OFF. Ini tetap prerelease: katalog 47 fitur belum lengkap dan bukti unit/probe tidak berarti seluruh efek gameplay telah dikualifikasi. Detail akar masalah, perubahan dan pengujian: [laporan perbaikan RC3](../CRASH_REPAIR_RC3.md).

Validasi build: lima ELF dengan alignment 16 KiB, Java/DEX, 16 package regression tests, 9 catalog tests, 5 unit Android, 8 installer cases dan executable ARM64 dispatcher/emitter probe melalui Houdini. CI mengulang host unit dan build/package checks; pengujian game aktual dilakukan terpisah.

Aset: `wsm-v6.1.0-rc3.zip`, checksum SHA-256 dan `ci-build-provenance.json`. Checksum build lokal yang diuji perangkat dapat berbeda dari build CI; gunakan checksum aset release yang diunduh.
