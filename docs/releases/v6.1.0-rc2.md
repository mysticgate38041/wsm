# WSM 6.1.0 RC2

Modul Android dual-ABI untuk `com.kakaogames.gdts` **3.54.0 / versionCode 423**, API ≥26. Rilis ini merupakan **prerelease dengan scope 47 fitur belum lengkap**, bukan klaim final semua efek gameplay.

## Perubahan utama

- Full-signature IL2CPP binding, target identity exact, perbaikan resolver Time Scale instance dan ownership modifier `wsm`.
- Katalog seluruh 47 fitur desain dalam JSON, menu dan 12 halaman native; 18 kontrol native aktif, 31 fitur desain tanpa backend aktif.
- Critical Damage Scale hero-only ×1–5, restore slot 26, relokasi ADR/ADRP dengan range checks dan direct tail branch yang mempertahankan register prologue.
- Revision token UI menolak completion stale/out-of-order; pending gate; PANIC meningkatkan epoch dan menolak producer sesi lama.
- Bounded worker/queue, ledger opsi, patch 4 byte, alias readback/protection/rollback serta quarantine timeout.
- Build receipt source/binary, ZIP 14 entry, checksum/manifest, qualification gates, sembilan snapshot tests dan 16 package tests.
- GitHub Actions build/test otomatis dan CD tag-gated ke private GitHub prerelease. Snapshot mode membuat clone dapat dibangun tanpa dump/database eksternal.

Checksum release diambil dari aset pendamping. Source archives GitHub mengacu pada tag yang sama. Dump mentah, APK game, database besar, signing keys dan toolchain tidak dibundel.

## Validasi dan batasnya

CI menjalankan empat unit native host, sembilan tests snapshot, Java state tests, pemeriksaan lima ELF/DEX dan 16 tests paket. Unit Android dikompilasi dalam build CI.

Bukti sebelum publikasi: empat unit Android dan delapan kasus installer harness PASS pada LDPlayer API 34; eksekusi ARM64 emitter sintetis melalui native bridge PASS, APK probe dihapus. Ini merupakan probe terisolasi; tidak menguji efek RC2 pada game, perangkat ARM64 fisik atau persistence. Audit dump asli mencocokkan 155/155 input; CI memakai snapshot dan tidak mengulang audit dump eksternal.

Katalog: **14 partial, 2 prototype, 16 not_implemented, 10 authority_unverified, 5 target_absent**. Seluruh fitur masih `runtimeAcceptance=UNVERIFIED` untuk semantik kandidat; gate `completed=0` dipertahankan. ACK sukses tidak berarti efek gameplay sesuai desain. Getter critical damage dan Time Scale baru tetap perlu acceptance game. Lifetime objek dan Unity main-thread affinity juga belum sepenuhnya dibuktikan.

## Penggunaan

Cocokkan checksum, target version dan ABI; pasang menggunakan pengelola modul dengan provider Zygisk yang sesuai, lalu reboot manual. Semua kontrol mulai OFF dan profil tidak otomatis diterapkan. Uji satu fitur per sesi berikut OFF/PANIC dan lifecycle. Pemulihan melalui penonaktifan `wsm_gt` dan reboot. Build/CD tidak memasang kandidat ke perangkat.
